We develop and contribute to open-source software for genomics, data analysis, and bioinformatics education.

## Lab Software

### [valr](https://github.com/rnabioco/valr)
Genome interval arithmetic in R. Provides tools for manipulating and analyzing genome intervals, inspired by BEDtools, with a tidy interface.

### [clustifyr](https://github.com/rnabioco/clustifyr)
Classify cells in single-cell RNA sequencing experiments using reference bulk RNA-seq or single-cell datasets.

## Educational Resources

### [MOLB 7950](https://github.com/rnabioco/molb-7950)
Course materials for Molecular Biology 7950: Practical Biological Data Analysis in R.
